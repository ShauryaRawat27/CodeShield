SYSTEM OVERVIEW

How CodeShield works

CodeShield is a context-aware security drift platform that analyzes repository configuration and runtime evidence.

The idea in one sentence

CodeShield compares what an application is supposed to use with what its deployed environment actually exposes and executes.

01

Application intent

Saved baselines describe approved runtime versions, image digests, dependency versions, users, and network exposure.

→
02

Runtime evidence

A scan reads repository configuration, accepts runtime observations, or triages an uploaded application log window.

→
03

Drift engine

Deterministic rules compare both states and preserve the evidence behind every detected mismatch.

→
04

Risk and response

Criticality, Internet exposure, and exploit evidence adjust priority. Users then resolve, accept, or reopen findings.

IMPLEMENTED

Current capabilities

  • Persistent application baselines
  • Public Git URL and local repository configuration scans
  • Configurable runtime evidence scans
  • Six explainable drift rules
  • Aggregated log triage with six explainable signals
  • Context-aware risk scoring
  • Evidence and remediation detail
  • Finding workflow and scan history
  • JSON REST API and H2 database

ANALYSIS MODES

Use repository, runtime, or log evidence

  1. Register the intended secure baseline for an application.
  2. Scan a public Git URL or local repository to extract configuration evidence automatically.
  3. Submit live observations manually or through the REST API when runtime data is available.
  4. Paste or upload a log window to group repeated security-relevant events.
  5. Review expected and observed states, evidence, risk, and remediation.
